Lieber angehender Benutzer von ELECTRIP, im Folgenden eine kleine Anleitung zur Installation und Benutzung.
Das komplette Benutzerhandbuch liegt als Pdf-Datei im selben Verzeichnis vor und ist dieser Kurzanleitung in jedem Fall vorzuziehen.

------Systemvorraussetzungen------
Hardware:
• Einen alten PC mit serieller Schnittstelle
• Tastatur
• Maus
• Bildschirm
• Gamepad mit Rundblickschalter (z.B. Logitech RumblePad 2, PlayStation oder xbox-controller...)
• Booster (z.B. Märklin Delta)
Software:
• SRCP-Server (z.B. Srcpd)
• python 2.6
• gtk >= 3.0 (ab ELECTRIP-Version 2.0.0. wenn nur gtk>=2.6 vorhanden, muss ELECTRIP-1.7.0 installiert werden)
• pygame

------Installation------
1. Rufen Sie http://sourceforge.net/projects/electrip/files auf.
	a) Empfohlen: Wenn Sie die neueste Version von ELECTRIP verwenden wollen, laden Sie die Datei „ELECTRIP-2.0.2.tar.gz“  herunter.
	b) Wenn Sie Unterstützung für GTK2 benötigen (z.B. auf Windows oder Mac OS X), laden Sie die Datei „ELECTRIP-1.7.0-gtk2.tar.gz“ herunter.
	Entpacken Sie die Datei an einen beliebigen Ort in ihrem Dateisystem.
2. Mit einem Doppelklick auf die Datei „ELECTRIP_Configuration.py“ starten Sie ELECTRIP.

------Probleme------
Sollten Sie ein Problem bei der Installation oder der Benutzung von ELECTRIP haben,
wenden Sie sich bitte im Forum auf sourceforge.net persönlich an mich. Gehen Sie hierzu
auf https://sourceforge.net/projects/electrip/forums/forum/1824674.
