Lieber angehender Benutzer von ELECTRIP, im Folgenden eine kleine Anleitung zur Installation und Benutzung.
Das komplette Benutzerhandbuch liegt als Pdf-Datei im selben Verzeichnis vor und ist dieser Kurzanleitung in jedem Fall vorzuziehen.

------Systemvorraussetzungen------
Hardware:
• Einen alten PC mit serieller Schnittstelle
• Tastatur
• Maus
• Bildschirm
• Gamepad mit Hat-Switch (z.B. Logitech RumblePad 2, PlayStation oder xbox-controller...)
• Booster (z.B. Märklin Delta)
Software:
• SRCP-Server (z.B. Srcpd)
• python 2.6
• pygtk >= 2.6
• pygame

------Installation------
1. Wählen Sie auf http://electrip.svn.sourceforge.net/ „Download GNU tarball“ und
entpacken Sie die Datei an einen beliebigen Ort in ihrem Dateisystem.
2. Im Ordner ~./trunk finden sie die Datei „ELECTRIP_Configuration.py“. Linuxnutzer markieren diese als ausführbar.
3. Mit einem Doppelkick auf „ELECTRIP_Configuration.py“ starten Sie ELECTRIP.

------Probleme------
Sollten Sie ein Problem bei der Installation oder der Benutzung von ELECTRIP haben,
wenden Sie sich bitte im Forum auf sourceforge.net persönlich an mich. Gehen Sie hierzu
auf https://sourceforge.net/projects/electrip/forums/forum/1824674.
