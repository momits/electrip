# Electrip 2

Neuentwicklung von [Electrip](https://sourceforge.net/projects/electrip/) – Modellbahnsteuerung mit Gamepads – in Rust, gebaut von KI-Agenten.

- `legacy/` – Quellcode von Electrip 1 (Python/GTK) mit vollständiger Git-Historie, als Referenz und Test-Orakel
- `spec/` – Gesamtkonzept, Benutzerhandbuch von Electrip 1, Anforderungen
